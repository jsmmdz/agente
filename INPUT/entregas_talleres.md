# Entregas de talleres

Esta es la única fuente de fechas del agente: si una entrega no está acá, no existe
para él y tiene prohibido inventarla.

Estados posibles: `Sin empezar` · `En proceso` · `Entregado`
Formato de fecha: `AAAA-MM-DD` (ej. `2026-09-15`). Si todavía no sabés la fecha,
escribí `Sin fecha` — el agente lo va a decir explícitamente en vez de asumir una.
